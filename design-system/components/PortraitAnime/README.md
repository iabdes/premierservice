# PortraitAnime

Le portrait de l’invité qui s’anime légèrement, en boucle de 3 secondes, découpé en disque.

- Fournir : la vidéo `premier-service_portrait-anime_<prénom-nom>.mp4` (groupe Portraits-animes) et, en image d’attente, le portrait fixe `premier-service_portrait_<prénom-nom>.jpg`.
- Balise : `<video autoplay muted loop playsinline poster="…">`, disque (`radius-rond`), bord blanc 5 px. Toujours un nom accessible (« Portrait animé de … »).
- Mouvement réduit demandé : remplacer par le portrait fixe.
- Usages : bulles de l’accueil, bloc du prochain invité, stories et publications vidéo. Pas plus de six visibles à la fois ; lancer la lecture seulement quand le portrait est à l’écran.
- Ne pas : ajouter du son, des commandes, un recadrage carré, ou accélérer la boucle.
