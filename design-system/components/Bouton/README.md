# Bouton

Les boutons pilule (`radius-pilule`), 48 px de haut au moins, texte `site-bouton`, verbe d’action qui dit ce qui se passe.

- Plein (`bleu-marine`, survol `marine-survol`) : l’action principale, « Rejoindre le club », « Candidater pour ce rendez-vous ». Un seul par écran.
- Contour (`bleu-marine`, se remplit au survol) : l’action secondaire, « Toute la saison », « Voir le film ».
- Blanc sur `bleu-marine` : slide d’action d’un carrousel, avec l’adresse en dessous en `texte-sur-bleu`.
- Argonautes : bouton « lesargos.fr » de la carte partenaire, qui passe au `argo-rouge` au survol (seul usage de ce rouge sur le site).
- Focus : anneau `ciel` de 3 px, décalé de 3 px. Liens externes dans un nouvel onglet.
- Libellés de référence : « Rejoindre le club », « Candidater », « S’inscrire sur Alumni Platform », « Toute la saison ».
