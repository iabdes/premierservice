Le principe

10 étudiants + 1 invité

Une table

Dix étudiants et une personnalité publique. Assez peu pour que chacun parle, assez pour que les questions se croisent.

Ce qui se dit à table reste à table.

Sans caméra, sans citation

À huis clos

Pas de caméra pendant l’échange, pas de citation sans accord. L’invité parle d’expérience, pas de position.

Le soir ou le matin

Deux formats

Le dîner, le soir, pour prendre le temps. Le petit-déjeuner, le matin, quand l’agenda de l’invité est plus serré.

Après la table, le club

Chaque rendez-vous fait entrer dix étudiants dans le club Premier Service. On s’y retrouve, on s’entraide, on suit les parcours de chacun.

  • L’annuaire

    Tous les membres, leurs études et leurs engagements, mis à jour par chacun.

  • Les événements

    Inscription aux rendez-vous et aux rencontres du club.

  • La lettre

    Les prochains invités et les nouvelles des membres.

  • Le groupe WhatsApp

    Pour les membres inscrits sur Alumni Platform.
